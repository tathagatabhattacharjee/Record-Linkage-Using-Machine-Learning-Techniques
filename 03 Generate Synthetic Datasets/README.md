
<H1>Generate Synthetic Datasets</H1>
This folder contains the synthetic data generation and privacy-preserving data preparation components used in the Record Linkage Using Machine Learning Techniques project.
<BR><BR>
The purpose of this stage is to create realistic datasets for record-linkage experiments while preserving important characteristics of the source data. The workflows cover generative modelling with CTGAN, improved synthetic data generation with a better-distributed Date of Birth (DoB) field, and deterministic name masking for privacy-preserving experiments.
